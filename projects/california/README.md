# California Housing Price Prediction

## Project Goal

使用 California Housing Dataset 建立房價預測模型，透過 Python 與 Scikit-learn 練習機器學習回歸分析。

## CRISP-DM Process

1. Business Understanding
2. Data Understanding
3. Data Preparation
4. Modeling
5. Evaluation
6. Deployment

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Regression Model

## Result

本專案使用回歸模型預測房價，並透過 RMSE 與 R² 評估模型表現。

## Learning

透過此專案，我學習到如何從資料理解、前處理、模型建立到模型評估，完整走過一個機器學習專案流程。
