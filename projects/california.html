🏠 California Housing

Machine Learning Regression Project

使用 Scikit-learn 建立加州房價預測模型

🎯 Project Goal

本專案使用 California Housing Dataset， 建立房價預測模型， 比較不同特徵的重要性， 並利用機器學習提升預測準確率。

📋 CRISP-DM 流程

  1. Business Understanding
  2. Data Understanding
  3. Data Preparation
  4. Modeling
  5. Evaluation
  6. Deployment

🛠 Technologies

Python Pandas NumPy Scikit-learn Matplotlib Regression

📊 Result

利用 Feature Selection 比較不同特徵數量， 並觀察 RMSE 與 R² 的變化， 找出最佳模型。
